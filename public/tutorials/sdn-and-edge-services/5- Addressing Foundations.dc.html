Addressing & Subnetting

Two addresses run every network: one burned into the hardware, one assigned by you. Learn both — then slice a network into exactly the subnets you need.

⏱️ ~27 min 📑 15 chapters 🧠 3 quizzes 🎯 CIDR calculator
Prepared by Reza Shahabian
Chapter 01 · The big picture

Every device has two addresses

🏷️
MAC address
Layer 2 · Data Link
00:1A:2B:3C:4D:5E
• Burned into the hardware — a permanent ID
• Used within a local network
• 48 bits, hexadecimal
📮
IP address
Layer 3 · Network
192.168.1.1
• Assigned logically — can change
• Used between networks; makes routing possible
• 32 bits (IPv4) or 128 bits (IPv6)
🔗 Both are required. IP guides data across networks; MAC delivers it within one. You'll see exactly how they hand off in the ARP chapter.
Chapter 02 · The hardware ID

MAC addresses

A unique identification number given to the Network Interface Card of a device — 48 bits, written as six hexadecimal pairs.

00 1A 2B 3C 4D 5E
FIRST 24 BITS — OUI
identifies the manufacturer
LAST 24 BITS
unique to this device
💡 When computers, phones or printers exchange data over Ethernet or Wi-Fi, MAC addresses ensure it reaches the correct device. Think of it as a permanent hardware ID.

Chapter 03 · Anatomy of an IPv4 address

Network part, host part

32 bits, written as four octets of 8 bits each, separated by dots. Every octet ranges from 0 to 255.

192. 168. 1. 1
NETWORK ID
which network the device is on
HOST ID
which device on that network
the split between them is set by the subnet mask — that's what the next chapters are about
🧮 Each octet is 8 bits, so 4 × 8 = 32 bits total — which is why IPv4 has roughly 4.3 billion possible addresses, and why we ran out.
Chapter 04 · Two worlds of address

Public vs private addresses

🌍 Public IP

A globally unique address that can be accessed over the internet. Assigned by Internet Service Providers.

🔒 Private IP

Used inside private networks — homes, offices, organisations. These addresses cannot be routed on the internet.

The three private ranges — worth memorising
10.0.0.0/8
10.0.0.0 – 10.255.255.255
172.16.0.0/12
172.16.0.0 – 172.31.255.255
192.168.0.0/16
192.168.0.0 – 192.168.255.255
Chapter 05 · Running out of numbers

IPv6

IPv6 uses 128-bit addresses written in hexadecimal. It was developed to replace IPv4 because IPv4 addresses are limited and were becoming exhausted.

2001:0db8:85a3:0000:0000:8a2e:0370:7334
eight groups of four hexadecimal digits
IPv4 — 32 bits
~4.3 billion
addresses — and they ran out
IPv6 — 128 bits
340 undecillion
a 3.4 followed by 38 zeros
