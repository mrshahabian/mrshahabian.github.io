Chapter 04 · The core split

Control plane vs data plane

This single separation is the whole idea of SDN — and one of your session learning outcomes.

🧠
Control Plane
Decision making

The SDN controller decides the best path for network traffic, based on rules, policies and current network conditions.

➡️
Data Plane
Traffic forwarding

Switches and routers simply follow the instructions the controller gives them, forwarding packets accordingly.

📡

How they talk: the controller communicates with devices using protocols such as OpenFlow — sending down rules, and receiving status updates back.

Chapter 09 · Part two of the module

What are Edge Services?

Handling data and delivering services as close as possible to the end user — reducing delays and improving overall system performance.

Edge services reduce the workload on centralised cloud data centres by performing processing locally.
